# 効果測定用のサンプル音声

`cli/tests/noise_reduction.rs` が使う、ノイズ除去の効果を数値で測るための音声です。

| ファイル | 内容 |
|---|---|
| `clean.wav` | 雑音のない音声。測定の正解として使う |
| `noisy.wav` | `clean.wav` に雑音を重ねたもの。これを処理する |

いずれも 48 kHz / モノラル / PCM 16bit、189,284 フレーム（3.943 秒）です。

## 測定が成り立つ条件

2つのファイルは **`noisy = clean + 雑音` の関係にあり、長さと時間位置が完全に一致している**必要があります。別々に録音したものではSN比を差分で求められません。

この条件が崩れると測定は無意味になるため、テストは長さの一致を検査し、処理後の時間ずれも相互相関で確認します。

## 自分の音声で測る

環境変数で別のファイルを指定できます。

```bash
DEEPFILTER_CLEAN=/path/to/clean.wav \
DEEPFILTER_NOISY=/path/to/noisy.wav \
  cargo test --test noise_reduction -- --nocapture
```

指定がなければこのフォルダーのファイルを使い、どちらもなければ理由を表示してテストを飛ばします。
